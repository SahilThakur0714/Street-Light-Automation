🌃 Street Light Automation System
This project is a smart Street Light Automation System using LDR, PIR sensor, LED, and Arduino UNO. It automatically turns ON street lights when it gets dark and motion is detected, helping save electricity.
The LDR (Light Dependent Resistor) detects ambient light levels. If the environment is dark, the system becomes active. The PIR sensor checks for human or vehicle motion. When motion is detected, LEDs light up. If no motion is detected for a while, the lights turn OFF.
The system is built on a breadboard using basic components and programmed in C++ via Arduino IDE. It's a beginner-friendly embedded systems project that promotes energy efficiency.


🔧 Components:
1. Arduino UNO

2. LDR

3. PIR Sensor

4. LEDs

5. Breadboard & Wires

6. C++ (Arduino IDE)

Ideal for smart city concepts and real-world energy-saving solutions.
